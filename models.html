Anthropic
(Claude 3.5 · 3.7 · Claude Code · 5.5)		 헌법적 AI 안전 정렬과 실무·코딩 신뢰성 극대화 최상위 코딩·아키텍처 이해력, 자연스러운 문체, 카파시 합류로 가속된 사전학습·터미널 에이전트 표준 비교적 보수적인 안전 거절 정책(일부 맥락), 상대적으로 높은 API 단가와 토큰 제한 소프트웨어 개발·리팩토링(Cursor/Claude Code), 정교한 문서·리서치
Google
(Gemini 1.5 · 2.5 · Gemini 3/4)		 네이티브 멀티모달과 초장문 맥락, 자사 인프라 수직 통합 100만~200만 토큰 초장문 처리, 영상·음성 네이티브 이해, 검색·Workspace·TPU 클라우드 결합 초기 Bard 시연 실수로 인한 브랜드 출발 지연, 대화 톤·일관성 기복 이슈 긴 영상·오디오 분석, 수만 페이지 자료 통째 요약, 구글 생태계·클라우드 연동
